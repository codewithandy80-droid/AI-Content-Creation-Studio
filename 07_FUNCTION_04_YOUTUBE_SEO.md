# 7. Function 04 — YouTube SEO Generation

## Purpose
Create YouTube metadata and packaging suggestions aligned with the approved source, analysis, script, and thumbnail concept.

## Inputs
- Approved analysis version.
- Approved script version where available.
- Thumbnail prompt concepts and title context where available.
- Master Language.
- Shorts/long-video format and selected duration.
- Research findings only if separately enabled, reviewed, selected, and integrated into an approved analysis version.

## Required output
- Multiple title options.
- One recommended title.
- Description.
- Tags.
- Primary and secondary keywords.
- Hashtags.
- Title/thumbnail alignment check.
- Retention/story packaging suggestions where appropriate.
- Shorts/long-video guidance where relevant.
- AI-generated visuals disclosure guidance only as a release-time item to verify against current platform requirements; do not present unverified policy text as current fact.

## Rules
- SEO language follows Master Language.
- Keep all factual claims consistent with the approved analysis and script.
- Do not promise rankings, views, or virality.
- Do not automatically add clickable source links. No clickable links anywhere in the app, output, or export.
- If live keyword research is used, it must be a separately configured research dependency and must obey the free-only rule. Current decision register does not freeze a specific search provider or live-keyword service.
- Exact title-option count and description length/template remain configurable/pending; choose a transparent default during implementation and record it, rather than claiming it was explicitly selected in the source.
- Output is Draft by default; optional auto-approval is allowed only when explicitly enabled for SEO and all critical quality checks pass.
- Revisions create new versions and preserve the prior approved output.

## Validation
- Required fields exist and are in the Master Language.
- No factual metadata claims unsupported by the approved analysis.
- Tags and hashtags are formatted consistently.
- Title and thumbnail concept are aligned and not materially misleading.
- No clickable links or auto-inserted source URLs.
- AI disclosure guidance is reviewed against current platform policy before release.

## Acceptance criteria
- AC-F04-01: Title options and one recommended title are present.
- AC-F04-02: Description, tags, keywords, and hashtags are present.
- AC-F04-03: Language matches Master Language.
- AC-F04-04: Factual consistency checks pass.
- AC-F04-05: No clickable links appear in any SEO output or export.
- AC-F04-06: No ranking/virality guarantees.
- AC-F04-07: Policy-dependent disclosure wording is marked for current verification.

## Hinglish
SEO mein titles, recommended title, description, tags, keywords aur hashtags honge. Live research aur exact lengths final technical/product defaults ke roop mein set karne honge; ranking ya viral hone ki guarantee nahi deni.
